# เลขที่สัญญาจังหวัด / โรงพยาบาล — ตรวจสอบก่อนเผยแพร่

สาขานี้ใช้หน้าและฐานข้อมูล Cloudflare เดิม เพิ่มหน้าเลือกประเภท, ฟอร์มเดิม, ตัวกรองการรับส่ง, ชื่อผู้ส่ง/รับและเวลา โดยไม่เปลี่ยนค่ารหัสรับแฟ้มเดิม
- contract_type เป็น province หรือ hospital; API เดิมที่ไม่ได้ระบุ type คืนเฉพาะ province เพื่อรักษาความเข้ากันได้
- เลขโรงพยาบาลเก็บรูป HOSPITAL-<เลข/ปี> ภายในเพื่อไม่ชน UNIQUE เดิม และแสดงเฉพาะเลข/ปีผ่าน API; ID แฟ้มและไฟล์แนบไม่เปลี่ยน
- คงขั้นตอนรอออกเลขและแก้เลขเดิมไว้ ไม่สร้างเลขจริงจากค่าคาดเดา
- ห้ามตั้ง HOSPITAL_REGISTER_READY=true จนกว่าจะตรวจฐาน D1 จริงและ Master ของโรงพยาบาล, ย้ายรายการโรงพยาบาลที่มีอยู่แล้วโดยใช้ ID เดิม, ตรวจจำนวนและเลขล่าสุด และเพิ่ม Master sync แยกชีตโรงพยาบาล (โค้ดสาขานี้ตั้งใจยังไม่ซิงก์ hospital ไปชีตจังหวัด)
- ก่อน deploy: สำรอง D1 เต็มพร้อมทดสอบคืนค่า; ตรวจ schema, unique index, trigger และข้อมูล legacy; ทดสอบด้วยสำเนาฐานข้อมูล ไม่ใช่ production; ตรวจเลขซ้ำแยกประเภท และทดสอบการส่ง/รับพร้อมกันหลายเครื่อง
- ทดสอบว่ารับก่อนส่งไม่ได้ กดซ้ำไม่ได้ รับด้วย key เดิมเท่านั้น ผู้ดำเนินการเป็นชื่อที่ผู้ใช้กรอก ไม่ใช่ตัวตนที่ตรวจยืนยัน; ตรวจชื่อและเวลาหลัง reload; วันเวลาอิง server
- ตรวจไฟล์แนบ, ค้นหา, พิมพ์, แก้ไข, ผู้เรียก API เก่า, Master sync จังหวัด และระบบปลายทางบริหารสัญญา/หลักประกันก่อนเปิดใช้งาน
- ข้อมูลวันส่ง/รับเก่าเก็บไว้ ไม่อนุมานชื่อผู้ดำเนินการย้อนหลัง
- ยังไม่ได้ทดสอบกับ D1 จริงหรือเผยแพร่จากสาขานี้; การรับหลายรายการพร้อมกันและซิงก์สถานะไประบบปลายทางยังไม่รวมในสาขานี้
